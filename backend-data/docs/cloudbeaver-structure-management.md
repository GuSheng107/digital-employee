# CloudBeaver 数据库结构管理说明

数据库结构管理由服务器独立部署的 CloudBeaver Community 负责。

## CloudBeaver 负责

- 创建数据库。
- 创建数据表。
- 修改字段。
- 创建索引。
- 调整表注释和字段注释。
- 管理结构变更审批和执行。

## 数据中台负责

- 连接已有数据库。
- 使用 SQLAlchemy model 映射已有表。
- 通过 API 封装查询和必要写入。
- 做健康检查、异常处理、日志记录和统一响应。

## 禁止在数据中台实现

- DDL 预览。
- `CREATE TABLE` 执行。
- 任意 SQL 执行。
- 可视化建表页面。
- 启动时自动建表。
- 数据库迁移脚本自动执行。

## 表结构变更流程建议

1. 在需求或任务中说明表结构变更原因。
2. 由数据库负责人在 CloudBeaver 中执行结构变更。
3. 数据中台只更新对应 model、schema、repository、service 和 API。
4. 补充接口测试或服务层测试。
5. 通过 PR 审核后合并。
