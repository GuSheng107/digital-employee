## 已知初始关注点

### 1. 与 `web-dev` 的触发重叠

- 问题描述：用户说“新建页面”时，可能同时命中“规范开发”和“从零做页面”语义
- 触发输入：待后续补充真实样例
- 实际表现：待记录
- 期望表现：当重点是仓库内规范开发时命中 `frontend-dev-spec`；当重点是从零搭整站或完整 web app 时让位给 `web-dev`
- 原因：触发词存在交叉
- 修复点：观察 description 与触发样例覆盖是否足够
- 回归用例：参考 `evals/trigger-cases.md`

### 2. 与 `frontend-design` 的触发重叠

- 问题描述：用户说“优化页面”时，可能既指规范重构，也可能指视觉美化
- 触发输入：待后续补充真实样例
- 实际表现：待记录
- 期望表现：结构治理命中 `frontend-dev-spec`；视觉优化让位给 `frontend-design`
- 原因：用户表达模糊
- 修复点：加强排除边界描述
- 回归用例：补充“美化 UI”与“整理目录”对照样例

### 3. 重构模式误要求一次性全量迁移

- 问题描述：面对历史代码时，输出可能过于理想化，直接要求全量迁移到目标结构
- 触发输入：待后续补充真实样例
- 实际表现：待记录
- 期望表现：优先输出低风险、高收益的渐进方案
- 原因：模式规则未充分约束迁移节奏
- 修复点：持续加强 `references/refactor-mode.md`
- 回归用例：使用 `frontend/src/pages/PageA` 相关场景做人工回放
